# Brandy Database - MySQL Setup Guide

Complete guide for setting up MySQL database for the Brandy project on macOS.

## Why MySQL?

- ✅ Easier to install on macOS
- ✅ Often pre-installed or simpler setup
- ✅ Great for development and production
- ✅ Wide support and community
- ✅ Familiar to most developers

## Quick Start (macOS)

### Step 1: Install MySQL

**Option A: Using Homebrew** (Recommended)

```bash
# Install Homebrew if not already installed
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# Install MySQL
brew install mysql

# Start MySQL service
brew services start mysql

# Secure installation (set root password, remove test databases)
mysql_secure_installation
```

**Option B: Download Official Installer**

1. Download from [mysql.com/downloads](https://dev.mysql.com/downloads/mysql/)
2. Run the DMG installer
3. MySQL will start automatically

### Step 2: Install Python Dependencies

```bash
pip install mysql-connector-python
```

Or install all dependencies:

```bash
pip install -r requirements.txt
```

### Step 3: Configure Environment

```bash
# Copy environment template
cp .env.example .env

# Edit .env file
nano .env
```

Set these values:

```env
DB_HOST=localhost
DB_PORT=3306
DB_NAME=brandy
DB_USER=root
DB_PASSWORD=your_password_here  # If you set one during installation
DB_MAX_CONNECTIONS=10
```

### Step 4: Initialize Database

```bash
python database/init_db_mysql.py
```

You should see:

## Detailed Installation Guide

### Homebrew Installation (Detailed)

```bash
# 1. Install MySQL
brew install mysql

# 2. Start MySQL server
brew services start mysql

# 3. Check if MySQL is running
brew services list | grep mysql
# Should show: mysql  started

# 4. Connect to MySQL (no password by default)
mysql -u root

# 5. In MySQL shell, set a password (optional)
mysql> ALTER USER 'root'@'localhost' IDENTIFIED BY 'your_password';
mysql> FLUSH PRIVILEGES;
mysql> exit;
```

### Troubleshooting Installation

**Problem: "mysql: command not found"**

```bash
# Add MySQL to PATH
echo 'export PATH="/opt/homebrew/opt/mysql/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc
```

**Problem: "Access denied for user 'root'@'localhost'"**

```bash
# Reset root password
brew services stop mysql
mysqld_safe --skip-grant-tables &
mysql -u root

# In MySQL:
FLUSH PRIVILEGES;
ALTER USER 'root'@'localhost' IDENTIFIED BY 'new_password';
exit;

# Restart MySQL normally
killall mysqld
brew services start mysql
```

**Problem: MySQL won't start**

```bash
# Check logs
tail -f /opt/homebrew/var/mysql/*.err

# Remove lock files
rm /opt/homebrew/var/mysql/*.pid
brew services restart mysql
```

## Database Structure

### Tables

| Table | Purpose |
|-------|---------|
| `users` | User accounts and profiles |
| `events` | Event tracking (form submissions, API calls) |
| `form_submissions` | Form submission metadata |
| `form_answers` | Individual field answers (EAV pattern) |
| `generated_names` | Brand names generated by the system |
| `trademark_checks` | INDECOPI trademark search results |
| `similarity_checks` | Name-to-name comparison results |
| `cached_searches` | Database-based search cache |

### Views

- `v_form_submissions_complete` - Complete form data with aggregated answers
- `v_user_activity_summary` - User statistics
- `v_popular_names` - Most frequently generated names

## Usage Examples

### Using the Repository Classes

```python
from database.models_mysql import (
    UserRepository,
    EventRepository,
    FormSubmissionRepository
)

# Create a user
user_id = UserRepository.create(
    email='user@example.com',
    full_name='John Doe',
    company_name='Acme Inc',
    country='Peru'
)

# Create an event
event_id = EventRepository.create(
    event_type='form_submission',
    user_id=user_id,
    ip_address='192.168.1.1'
)

# Create form submission
submission_id = FormSubmissionRepository.create(
    user_id=user_id,
    event_id=event_id
)

# Add form answers
FormSubmissionRepository.add_answers_bulk(submission_id, {
    'resumen': 'E-commerce platform...',
    'publico': 'Millennials...',
    'personalidad': ['honesta', 'confiable', 'inspiradora']
})

# Retrieve submission
submission = FormSubmissionRepository.get_by_id(submission_id)
print(f"User: {submission['full_name']}")
print(f"Answers: {submission['answers']}")
```

### Direct SQL Queries

```python
from database.db_config_mysql import get_cursor, execute_query

# Using cursor
with get_cursor() as cursor:
    cursor.execute("SELECT * FROM users WHERE email = %s", ('user@example.com',))
    user = cursor.fetchone()
    print(user)

# Using helper function
users = execute_query(
    "SELECT * FROM users WHERE country = %s",
    ('Peru',),
    fetch='all'
)
```

## Database Management

### Connecting to MySQL

```bash
# Connect with root
mysql -u root -p

# Connect to brandy database
mysql -u root -p brandy

# Connect without password (if none set)
mysql -u root brandy
```

### Useful MySQL Commands

```sql
-- Show databases
SHOW DATABASES;

-- Use brandy database
USE brandy;

-- Show tables
SHOW TABLES;

-- Describe table structure
DESCRIBE users;

-- Show table creation statement
SHOW CREATE TABLE users;

-- Count records
SELECT COUNT(*) FROM users;

-- View recent form submissions
SELECT * FROM v_form_submissions_complete LIMIT 10;

-- User activity
SELECT * FROM v_user_activity_summary;
```

### Backup and Restore

**Backup:**

```bash
# Full backup
mysqldump -u root -p brandy > backup.sql

# Schema only
mysqldump -u root -p --no-data brandy > schema_backup.sql

# Data only
mysqldump -u root -p --no-create-info brandy > data_backup.sql

# Specific tables
mysqldump -u root -p brandy users events > users_events_backup.sql
```

**Restore:**

```bash
# Restore full backup
mysql -u root -p brandy < backup.sql

# Create database and restore
mysql -u root -p -e "CREATE DATABASE brandy"
mysql -u root -p brandy < backup.sql
```

### Reset Database

```bash
# Drop and recreate (WARNING: Deletes all data)
python database/init_db_mysql.py --drop

# Or manually:
mysql -u root -p -e "DROP DATABASE brandy; CREATE DATABASE brandy;"
python database/init_db_mysql.py
```

## Common Issues

### Issue: Connection Refused

**Solution:**

```bash
# Check if MySQL is running
brew services list

# Start MySQL
brew services start mysql

# Check port
netstat -an | grep 3306
```

### Issue: "Too many connections"

**Solution:**

```sql
-- Check current connections
SHOW PROCESSLIST;

-- Increase max connections
SET GLOBAL max_connections = 200;

-- Make permanent (add to my.cnf)
```

### Issue: Slow Queries

**Solutions:**

1. Enable slow query log:
```sql
SET GLOBAL slow_query_log = 'ON';
SET GLOBAL long_query_time = 2;  -- Log queries taking >2 seconds
```

2. Check slow queries:
```bash
cat /opt/homebrew/var/mysql/slow.log
```

3. Add indexes for frequently queried columns

### Issue: Character Encoding

**Solution:**

```sql
-- Check encoding
SHOW VARIABLES LIKE 'character_set%';

-- All tables are created with utf8mb4
-- If you need to convert existing table:
ALTER TABLE table_name CONVERT TO CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

## Security Best Practices

1. **Set Strong Password:**
```sql
ALTER USER 'root'@'localhost' IDENTIFIED BY 'strong_password_here';
```

2. **Create Dedicated User:**
```sql
CREATE USER 'brandy_app'@'localhost' IDENTIFIED BY 'password';
GRANT ALL PRIVILEGES ON brandy.* TO 'brandy_app'@'localhost';
FLUSH PRIVILEGES;
```

3. **Limit Permissions:**
```sql
-- For application user (no DDL)
GRANT SELECT, INSERT, UPDATE, DELETE ON brandy.* TO 'brandy_app'@'localhost';
```

4. **Enable SSL:**
```sql
-- Check SSL status
SHOW VARIABLES LIKE '%ssl%';
```

5. **Regular Backups:**
```bash
# Add to crontab for daily backups
0 2 * * * mysqldump -u root -p'password' brandy > /backups/brandy_$(date +\%Y\%m\%d).sql
```

## Monitoring

### Check Database Size

```sql
SELECT
    table_schema AS 'Database',
    ROUND(SUM(data_length + index_length) / 1024 / 1024, 2) AS 'Size (MB)'
FROM information_schema.tables
WHERE table_schema = 'brandy'
GROUP BY table_schema;
```

### Table Sizes

```sql
SELECT
    table_name AS 'Table',
    ROUND(((data_length + index_length) / 1024 / 1024), 2) AS 'Size (MB)'
FROM information_schema.tables
WHERE table_schema = 'brandy'
ORDER BY (data_length + index_length) DESC;
```

### Record Counts

```sql
SELECT
    table_name,
    table_rows
FROM information_schema.tables
WHERE table_schema = 'brandy'
ORDER BY table_rows DESC;
```

## Migration from File Cache

If you're migrating from the file-based pickle cache:

```python
from database.models_mysql import CacheRepository
import pickle
from pathlib import Path

cache_dir = Path('data/cache')

for cache_file in cache_dir.glob('*.pickle'):
    with open(cache_file, 'rb') as f:
        data = pickle.load(f)

    CacheRepository.set(
        query=data['query'],
        search_type=data['search_type'],
        results=data['results'],
        category=data.get('category'),
        expiry_days=7
    )
```
